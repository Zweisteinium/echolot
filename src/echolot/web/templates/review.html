The three answers

Perfect match
It is the song. The file is named and tagged as the song in your list.
Close match
Another version you take for the song, like an extended mix or a live take. The file keeps its real name, which you can edit. The song counts as covered. Missing lists these and can search again.
No match
Not the song. The file goes, this download is never taken for the song again, and the song is searched again.
